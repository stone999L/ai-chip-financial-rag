## 核验原则

1. 标题必须为“2026 年半年度报告”或“2026 年半年度报告全文”，不能误用“摘要”。
2. 证券代码与公司名称必须匹配。
3. 报告期必须为 2026H1。
4. 下载后脚本会再次检查响应是否为 PDF。
5. 未核验的链接保持为空，下载脚本会跳过，不用猜测 URL。
