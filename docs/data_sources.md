## 核验原则

1. 标题必须是“2026 年半年度报告”或“2026 年半年度报告全文”，不得误用“摘要”“业绩预告”或“披露提示性公告”。
2. 证券代码、公司名称、报告期必须匹配。
3. `scripts/discover_cninfo.py` 先通过证券代码解析 CNINFO orgId，再查询 2026 年半年度报告，过滤“摘要”等公告。
4. `scripts/verify_report_files.py` 会真实下载 PDF，检查 PDF 文件头、页数，并在前几页核验“2026”“半年度报告”以及公司名/证券代码。
5. 原始 PDF 不提交进 GitHub（体积较大），由下载脚本根据 manifest 自动获取。
