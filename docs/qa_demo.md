# Q&A 演示

## Q1 寒武纪 2026 年上半年营业收入及同比变化是多少？

**回答：**寒武纪 2026 年上半年营业收入为 **5,995,573,619.61 元**，上年同期为 2,880,643,471.09 元，**同比增长 108.13%**。公司说明，收入增长主要由于持续拓展市场并推动人工智能应用落地。

**证据：**寒武纪《2026 年半年度报告》第 7—8 页。  
**检索复核：**当前混合 Top-8 命中了同比增长说明，但没有稳定召回第 7 页合并口径营业收入表，同时召回了母公司利润表，因此该题被标记为“部分充分”。

## Q2 寒武纪在报告期内主要智能芯片产品及应用场景有哪些？

**回答：**寒武纪形成了云端产品、边缘产品、IP 授权及基础系统软件等产品体系。云端产品包括云端智能芯片及板卡、智能整机，并面向数据中心、智能计算中心和大模型训练/推理等场景；边缘产品面向智能制造、智能零售、智能教育、智能家居、智能电网等边缘计算场景。报告还列举了智慧城市语义检索与视频结构化分析、货载视觉智检、电力设备智能运维、智慧矿山安全生产监测、智慧交通事件检测等应用。

**证据：**寒武纪半年报第 10、14、16—19 页。  
**检索复核：**证据充分。

## Q3 海光信息的 CPU 与 DCU 分别主要面向哪些计算场景？

**回答：**海光 CPU 主要面向复杂逻辑计算、多任务调度等通用处理器场景，已应用于电信、金融、互联网、教育、交通、工业设计和图形图像处理等领域。海光 DCU 基于 GPGPU 通用并行计算思路，主要面向科学计算、人工智能计算、深度学习训练与推理、大模型和大数据处理，通常部署在服务器集群或数据中心。

**证据：**海光信息半年报第 15 页及相关产品说明。  
**检索复核：**BM25、向量、混合检索目标公司覆盖均为 100%，证据充分。

## Q4 龙芯中科在自主处理器生态建设方面有哪些进展？

**回答：**龙芯中科围绕自主指令系统 LoongArch 构建独立生态，报告期内继续推进龙架构 CPU 对外技术授权、支持合作伙伴基于龙芯 CPU IP 和龙架构研制芯片，并在高校推动人才生态和流片实践。软件方面，已形成与 X86、ARM 并列的 Linux 基础软件体系，持续完善二进制翻译、图形驱动和算力框架。报告称，与公司合作的厂商已达到上万家，下游开发人员达到数十万人。

**证据：**龙芯中科半年报第 11、14—16 页。  
**检索复核：**证据充分。

## Q5 景嘉微如何描述 GPU 产品及应用方向？

**回答：**景嘉微已形成 JM5400、JM7、JM9、JM11 等 GPU 产品系列，应用从高可靠嵌入式图形显示扩展到国产桌面、高端指控、测绘、态势感知、图形工作站、云桌面、云游戏和云渲染等场景。公司同时推进“高性能 GPU + 边端侧 AI SoC”双轮驱动战略，试图构建覆盖云、边、端的算力闭环。

**证据：**景嘉微半年报第 9—10、26 页。  
**检索复核：**证据充分。

## Q6 芯原股份的 IP 和定制芯片业务模式与直接销售标准芯片有何不同？

**回答：**芯原采用 SiPaaS 模式，不以销售自有品牌标准芯片为核心，而是通过半导体 IP 授权和芯片定制解决方案向客户提供服务。芯片定制可覆盖设计、晶圆制造、封装测试和量产管理；IP 业务获得授权使用费，并可在客户芯片量产后按约定取得特许权使用费。最终芯片产品销售主要由客户负责，因此其市场风险和库存风险模式与传统标准芯片厂商不同。

**证据：**芯原股份半年报第 15—17、49 页等。  
**检索复核：**证据充分。

## Q&A 演示结论

当前系统已经能够较稳定完成**单公司事实、产品、技术和商业模式问题**；对于**两公司比较、多公司筛选和全景归纳问题**，应该优先做问题拆分、按公司独立检索和覆盖率检查，再交给回答模型生成最终答案。
