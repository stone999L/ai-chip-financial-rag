# 10 道测试题的人工评分口径

本文件用于保证实验评价在看模型答案之前就固定下来，减少“看答案后再改标准”的主观性。具体事实与数字必须回到报告原文核验。

| 题号 | 主要判定标准 | 常见错误 |
|---|---|---|
| Q1 | 必须给出寒武纪 2026H1 营业收入及同比变化，且报告期、单位、同比方向正确 | 把营业总收入/营业收入混淆；取错上年同期；单位换算错误 |
| Q2 | 能从寒武纪报告中归纳主要智能芯片/产品与应用场景，并有对应原文证据 | 只列产品名不列场景；引用公司宣传外部知识 |
| Q3 | 正确区分海光 CPU 与 DCU 的主要用途/场景 | 把两条产品线混为一谈；只答其中一类 |
| Q4 | 回答龙芯中科处理器生态建设进展，至少覆盖软件/硬件或生态适配中的实际披露 | 泛泛说“自主可控”，缺少半年报证据 |
| Q5 | 依据景嘉微半年报描述 GPU 相关产品及应用方向 | 把行业常识当公司已披露事实；型号/场景错配 |
| Q6 | 正确解释芯原 IP 授权/芯片定制等业务与标准芯片直接销售的差异 | 把 IP 授权、设计服务和量产业务混淆 |
| Q7 | 同时覆盖瑞芯微和全志科技，并比较端侧智能计算布局 | 只召回一家公司；并列摘录但没有比较 |
| Q8 | 必须是多公司证据；指出研发投入/研发费用变化并解释报告披露的原因 | 只列金额不说明变化原因；不同口径横比 |
| Q9 | 跨 10 家全景归纳；至少形成云端 AI 算力、CPU/GPU、端侧 SoC、IP/定制、FPGA/可编程等可核验技术路线，并指出代表公司 | top-k 只覆盖少数公司，却写成“行业全景” |
| Q10 | 跨公司归纳共同技术、市场、供应链风险，并把应对措施与具体公司证据对应 | 把单家公司风险泛化为全部公司；措施无出处 |

## 正确性等级

- **正确**：核心结论完整，数字/口径/公司匹配，关键结论均能回链原文。
- **部分正确**：主要方向正确，但存在公司覆盖不足、证据缺项或次要口径问题。
- **错误**：核心数字或公司错配、关键关系错误、或主要结论缺少对应原文支持。
- **证据不足**：系统明确承认证据未覆盖，且未编造；这一状态不等同于“错误”，应单独记录检索问题。

## 跨公司题的附加指标

Q9、Q10 除人工正确性外，单独记录“公司覆盖率”：
`召回结果中出现的样本公司数 / 10`。

这能直接检验固定 top-k 在全景问题上的碎片化局限。
